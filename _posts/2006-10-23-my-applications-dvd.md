กันลืมครับ วิธีการทำ DVD ที่บรรจุเอา Windows XP รวมไปถึง Applications ต่างๆที่ผมต้องใช้ มีดังนี้ ขั้นแรก copy files ทั้งหมดจาก Windows XP CD ลงไปใน directory XPCD เสร็จแล้ว copy file applications ต่างๆที่ต้องใช้ลงไปเช่นพวก Microsoft Office, ULead, etc. จากนั้นให้ใช้โปรแกรม Bart's Boot Image Extractor ทำการ extract boot image file ออกจาก Windows XP CD โดยสามารถ download program ได้ที่ <a href="http://www.nu2.nu/download.php?sFile=bbie10.zip">BBIE</a> และอ่านวิธีการใช้ที่ <a href="http://www.nu2.nu/bbie/">BBIE Instruction</a> ขั้นตอนสุดท้ายจะเป็นการทำ .ISO image file สำหรับที่จะ burn ลง DVD ขั้นตอนนี้ทำโดยใช้โปรแกรม <a href="http://www.tech-hints.com/prog/cdimagegui.zip">CDImageGUI </a>โดยใน tab boot ก็ให้ชี้ไปที่ boot file ที่ได้จากขั้นตอนของ BBIE แค่นี้ก็เป็นอันเสร็จครับ และเพื่อกัน download file ไม่ได้ในอนาคตผมเลยเอามาเก็บไว้ที่ web ของผมด้วยซะเลย <a id="p67" href="/assets/uploads/2006/10/cdimagegui.zip">
