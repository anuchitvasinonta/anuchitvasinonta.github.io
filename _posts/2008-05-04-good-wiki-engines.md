I've been comparing many Wiki engines to be put on my site. For PHP based with or without MySQL, I think <a href="http://www.splitbrain.org/projects/dokuwiki">DokuWiki</a> and <a href="http://www.pmwiki.org/wiki">PMWiki</a> should be best suited. <a href="http://twiki.org">TWiki</a> is really good with a lot of features but it requires CGI::Session and a lot of tweaks at the server which will be a problem for non-root like me. DokuWiki also support USB version which is really neat. For more comprehensive comparison check out<a href="http://en.wikipedia.org/wiki/Comparison_of_wiki_software"> here</a>
