ถ้าต้องการรู้ว่ามีเพื่อนร่วมเครื่องที่ Host ด้วยกันอยู่กี่ web และมีใครบ้าง ไปที่นี่เลยครับ <a href="http://www.domaintools.com/reverse-ip/">ReverseIP</a> ที่ DomainTools ใส่ ip ของเครื่องที่ web เรา host อยู่เข้าไปซึ่งหาได้ไม่ยาก (ลอง ping ดูก็ได้หรือใช้ nslookup หรือ dnsstuff.com) ก็จะได้ list ของ web ทั้งหมดที่ร่วมชะตากรรมเดียวกันอยู่ออกมา สำหรับผมเอง (greatnote.com) มีเพื่อนร่วมห้องอยู่ตั้ง 139 คนแหนะ
