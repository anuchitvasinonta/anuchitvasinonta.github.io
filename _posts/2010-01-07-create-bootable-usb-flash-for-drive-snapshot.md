<p>หลังจากลองเลือก backup tool อยู่หลายตัว สำหรับ Windows 7 ก็มาจบที่ Drive Snapshot เพราะง่ายที่สุด โปรแกรมเป็นแค่ file เดียวเท่านั้น ราคาไม่แพงมาก ใช้งานง่าย ตัวอื่นๆที่เทียบดูก็มี Acronis (Features เยอะ GUI สวย แต่แพงกว่าพอสมควร), Macrium Relflect (ลอง create boot cd แล้วไม่ work สำหรับแบบ linux แบบ BartPE ต้องไป download PEBuilder แล้วมาทำอีก) สำหรับ Drive Snapshot ราคา 39 Euro มี Boot Image สำหรับ Diskette มาให้ ลอง restore เข้าไปใน usb flash ก็ใช้ได้เลย มี drivers ของ USB Drives ให้เรียบร้อย ตามวิธีที่ระบุไว้ใน <a title="http://www.drivesnapshot.de/en/Tips.htm" href="http://www.drivesnapshot.de/en/Tips.htm">http://www.drivesnapshot.de/en/Tips.htm</a> ส่วนถ้าต้องการ customize เช่นใส่ tool อื่นๆเพิ่มก็ทำได้โดย</p>  <p>1. Download และ Install HP Drive Key Boot Utility <a href='/assets/uploads/2010/01/hpusbdisk.exe'>hpusbdisk</a></p>  <p>2. จาก program Drive SnapShot เลือก View Contents of Saved Disk Image จะได้ virtual drive มา</p>  <p><a href="/assets/uploads/2010/01/image.png"><img style="border-bottom: 0px; border-left: 0px; display: inline; border-top: 0px; border-right: 0px" title="image" border="0" alt="image" src="/assets/uploads/2010/01/image.png" /></a> </p>  <p><a href="/assets/uploads/2010/01/image1.png"><img style="border-bottom: 0px; border-left: 0px; display: inline; border-top: 0px; border-right: 0px" title="image" border="0" alt="image" src="/assets/uploads/2010/01/image1.png" width="400" /></a> </p>  <p>3. ให้เลือก Map and Explore Virtual Drive จากนั้น Run HP Utility แล้ว set ตามรูปด้านล่าง เลือก Virtual Drive Location สำหรับ DOS System ในที่นี้เป็น Drive Z:</p>  <p><a href="/assets/uploads/2010/01/image2.png"><img style="border-bottom: 0px; border-left: 0px; display: inline; border-top: 0px; border-right: 0px" title="image" border="0" alt="image" src="/assets/uploads/2010/01/image2.png" /></a> </p>  <p>4. Copy File หรือ Utilities อื่นๆใส่ตามต้องการ</p>  <p>Note : ถ้าจะใช้ Spinrite ห้าม enable NTFS Support เพราะจะทำให้ memory ไม่พอ ยังไม่รู้แก้ยังไง แต่ ก็ไม่จำเป็นสำหรับการ run spinrite</p>  <p>** ผมว่าเป็น Perfect Combination สำหรับ user ทั่วไป Snapshot + Spinrite สองไฟล์รวมกันขนาดยังไม่ถึง 1MB เลย</p>
