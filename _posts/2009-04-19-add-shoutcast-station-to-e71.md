Here's how I added the stations from <a href="http://www.shoutcast.com">shoutcast.com</a> to my Nokia E71 Internet Radio application. First find the station you want using search or directory. Then click the "TUNE IN!" icon and then in the new pop-up window, select Listen in Winamp or Other Player
<img width=400 src="/assets/uploads/2009/04/shoutcast1.jpg" alt="null" />
Select second option
<img width=400 src="/assets/uploads/2009/04/shoutcast2.jpg" alt="null" />
Click Save. A dialog box for download or save as pops up. Select Save As... and save the file as .pls file
<img src="/assets/uploads/2009/04/shoutcast3.jpg" alt="null" />
Open the file with Wordpad and note the address of the station to be added manually in Internet Radio app on E71. That's it.
