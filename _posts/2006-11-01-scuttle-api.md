I couldn't find the API documentation for Scuttle Bookmarking but seems like it is very similar to the del.icio.us which you can read the help documentation here <a href="http://del.icio.us/help/api/">http://del.icio.us/help/api/</a> and one undocumented keyword in "all". For example if you want to delete all bookmarks, in the scullte you would run .../scuttle_directory/api/posts_delete?url=all. Note that this will prompt you for the username and password if you have not logged in. Also note that the api file name is different from the del.icio.us ones, so you will have to check which api files are available yourselves in the api directory.
