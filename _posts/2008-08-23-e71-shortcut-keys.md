เก็บมาจาก E71fanatics

Shift+center d-pad = เลือกคำเดียว
Shift+d-pad down/up = เลือกหลายคำ
Ctrl+a, Ctrl+c, Ctrl+v = เลือกทั้งหมด, copy, paste แต่กดหลาย key ไปหน่อย
Hold * = Bluetooth Shortcut
Hold # = เลือกระหว่าง General กับ Silent profiles
Hold 0 = เปิด browser
Hold HOME = applications list ที่เปิดอยู่
Hold Func then space bar = pop up writing options (predicative, language)
Hold Shift then Ctrl/Chr = change language

ใน browser
0 - home page
1 - bookmarks
2 - find text
3 - previous page
8 - page overview
9 - enter web address
* - increase zoom
# - decrease zoom
