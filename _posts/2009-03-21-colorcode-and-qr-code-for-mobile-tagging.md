<a href="/assets/uploads/2009/03/colorcode_example.png"><img class="aligncenter size-medium wp-image-299" style="border:0;" title="colorcode_example" src="/assets/uploads/2009/03/colorcode_example.png" alt="" width="129" height="129" /></a>วันก่อนได้มีโอกาสเจอ supplier เกาหลีเอา solutions ColorCode ของบริษัท <a href="http://www.colorzip.com">ColorZip</a> มาให้ดู เป็นลักษณะคล้ายๆ 2D barcode แต่ว่าใช้สีแทน ทำให้สามารถทำเป็นรูปต่างๆได้ และเอาไปใช้เป็น brand หรือ logo ของบริษัทหรือสัญลักษณ์ campaign ต่างๆได้ วิธีการใช้งานก็คือ ใช้โทรศัพท์มือถือที่ติดตั้งโปรแกรมสำหรับอ่าน ColorCode ซึ่ง <a href="http://www.colorcode.com.sg/Download.html">download</a> ได้พรี โดยโปรแกรมนี้จะใช้ camera ของมือถือในการ capture ColorCode แล้วก็จะส่งข้อมูลเป็น index ไปที่ code server เพื่อ query เอา url ที่ link ไปหา content กลับมาแ้ล้วก็ redirect browser บนมือถือให้ไปหา content  แต่เนื่องจาก ColorCode ถูกจดลิขสิทธ์โดย ColorZip อยู่ทำให้เวลาจะใช้ต้องไปขอเช่า Code ของเขาและ้ต้องไปเอาข้อมูล address ของ content จาก code server ของทาง ColorZip

<a href="/assets/uploads/2009/03/colorcode_process.png"><img style="border:0;" title="colorcode_process" src="/assets/uploads/2009/03/colorcode_process.png" alt="" width="400" /></a>

อีก solutions ก็คือ QR Code ซึ่งเป็นที่แพร่หลายกันทั่วไปแล้ว เป็น open standard มือถือใหม่ๆก็มักจะมีโปรแกรมสำหรับอ่าน 2D Code แบบนี้มาให้ด้วย เช่นผมใช้ Nokia E71 ก็มีมาให้เลย ถ้าไม่มีแนะนำให้ไป download read จากบริษัท <a href="http://www.upcode.com/page/1346211">Upcode</a> ซึ่งตัว reader ของ Upcode นี้ พออ่าน QR Code แล้วก็จะเปิด browser ไปที่หน้า url ที่อยู่ใน code โดยอัตโนมัติให้ ผมว่าสะดวกดีมาก นอกจากนี้เรายังสามารถ <a href="http://www.upcode.com/page/212810203">Generate Personal Code</a> ได้เองด้วยโดย Personal Code ก็คือ code ตัวเลขธรรมดาเพียงแต่เราสามารถตั้งค่าในโปรแกรม reader ของ upcode ได้ว่าถ้าเจอเลขนี้แล้วให้ไปที่ url ไหน ถ้าอยากได้ QR Code ที่เก็บ URL ไว้เลยก็ใช้ <a href="http://www.widgetbox.com/widget/winksiteqrcode">Widgetbox</a> อันนี้ได้เลยครับ ด้านล่างเป็น QR Code สำหรับ link มาที่ blog ของผมครับ
