ลองพยายาม set crontab ในสองสาม hosting ที่ใช้ทั้ง DirectAdmin และ Plesk แต่ไม่ work ทั้งแบบใช้ cron-curl.sh ของ drupal และ ใช้ /usr/bin/php /home/user/public_html/.../cron.php สุดท้ายก็มาใช้ poormanscron อย่างที่หลายๆคนแนะนำ ผมว่าดีกว่าอีกไม่ยุ่งดี และทุกอย่างอยู่ใน control ของเรา <a href="http://drupal.org/project/poormanscron">download ที่นี่</a> ครับ
