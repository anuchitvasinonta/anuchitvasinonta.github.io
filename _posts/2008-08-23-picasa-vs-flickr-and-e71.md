1. Picasa สามารถให้ upload/download file original ได้ Flickr ไม่ได้ (ต้องเสียเงิน)
2. Flickr มี tool ในการ upload จาก S60v3 ของ E71 มาให้เรียบร้อย (Share Online) แต่ Picasa ไม่มี
3. Flickr จำกัดการ upload ต่อเดือน Picasa จำกัดด้วยพื้นที่
4. Picasa security ไม่ดีเพราะถ้ามี link (ที่มี authcode ต่อท้าย) ก็สามารถเปิดดูได้ ถึงแม้จะ set เป็น unlisted ก็ตาม Flickr ยัง set ให้เป็น private ได้

ลองลง Shozu ดูแล้วเหมือนจะยังไม่ work ใน E71
